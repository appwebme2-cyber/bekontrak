Panduan API Kontrak MAESTRO

API baca-saja (read-only) untuk menarik daftar kontrak, detail, amandemen, dan progress ke sistem lain.

1. Ringkasan

Alamat dasar (Base URL)https://api.maestrokilang.com
Cadangan: https://bekontrak-production.up.railway.app
Format dataJSON (UTF-8)
MetodeHanya GET (tidak bisa mengubah data)
AutentikasiAPI key (tidak perlu login user)
Endpoint/api/public/contracts dan /api/public/contracts/{id}

2. Autentikasi (API key)

Setiap permintaan wajib membawa API key yang diberikan administrator. Ada dua cara mengirimnya:

CaraContohKapan dipakai
Header (disarankan)X-Api-Key: <API_KEY>Integrasi antar sistem, skrip, aplikasi.
Query di link?apiKey=<API_KEY>Dibuka cepat lewat browser.
Jaga kerahasiaan key. Key di dalam link tersimpan di riwayat browser dan log server, dan ikut terkirim bila link dibagikan. Jangan taruh key di kode aplikasi web yang berjalan di browser. Jika key bocor, minta administrator menggantinya.

3. Daftar Kontrak

GET/api/public/contracts

Parameter (semua opsional)

ParameterDefaultKeterangan
page1Nomor halaman.
pageSize50Jumlah data per halaman, maksimal 100.
allfalsetrue = ambil semua kontrak sekaligus tanpa paging (page dan pageSize diabaikan).
status-Saring berdasarkan status kontrak, penulisan harus persis seperti pada data (mis. Active, Completed).
tipe-Saring berdasarkan tipe kontrak (mis. Lumpsum, Unit Price, TSA/LTSA).
q-Cari kata di judul, nomor dokumen, nomor PO/PR, atau nama vendor.

Contoh

# 50 kontrak terbaru (halaman 1)
GET https://api.maestrokilang.com/api/public/contracts?apiKey=<API_KEY>

# Semua kontrak
GET https://api.maestrokilang.com/api/public/contracts?apiKey=<API_KEY>&all=true

# Halaman 2, 100 data per halaman, hanya yang Active
GET https://api.maestrokilang.com/api/public/contracts?apiKey=<API_KEY>&page=2&pageSize=100&status=Active

# Memakai header
curl -H "X-Api-Key: <API_KEY>" "https://api.maestrokilang.com/api/public/contracts?pageSize=10"

4. Detail Kontrak

GET/api/public/contracts/{id}

Ganti {id} dengan nilai id dari daftar kontrak.

GET https://api.maestrokilang.com/api/public/contracts/b3f1c2e4-...?apiKey=<API_KEY>

Isi respons

BagianKeterangan
Data kontrakid, judul, noDokumen, noPoPr, noIrkap, tipe, status, vendor, direksiPekerjaan, programKerja, planner

5. Kode Respons

KodeArtiPenanganan
200Berhasil.-
401API key tidak valid.Periksa key (tidak boleh ada spasi di awal/akhir).
404"API publik tidak aktif" atau "Kontrak tidak ditemukan".API belum diaktifkan administrator, atau id kontrak salah.
5xxGangguan di server.Coba lagi beberapa saat kemudian; hubungi administrator bila berulang.

6. Contoh Pemakaian Kode

JavaScript (Node.js / server)

const res = await fetch(
  "https://api.maestrokilang.com/api/public/contracts?all=true",
  { headers: { "X-Api-Key": process.env.MAESTRO_API_KEY } }
);
const { total, items } = await res.json();
console.log(total, items[0]);

Python

import os, requests
r = requests.get(
    "https://api.maestrokilang.com/api/public/contracts",
    headers={"X-Api-Key": os.environ["MAESTRO_API_KEY"]},
    params={"all": "true"},
    timeout=30,
)
r.raise_for_status()
data = r.json()
print(data["total"])

Excel / Power Query

Data → Get Data → From Web → Advanced, isi URL https://api.maestrokilang.com/api/public/contracts?all=true, tambahkan header X-Api-Key berisi key. Pilih items lalu Expand kolomnya.

7. Yang Tidak Disediakan

API ini sengaja tidak menampilkan data tagihan, file/dokumen, bukti progress (evidence), dan harga satuan. API ini juga hanya untuk membaca; tidak ada fungsi menambah, mengubah, atau menghapus data.

8. Catatan

  • Data selalu sesuai kondisi terbaru di sistem MAESTRO saat permintaan dibuat.
  • Untuk daftar besar, gunakan page dan pageSize daripada all=true agar respons lebih ringan.
  • Untuk meminta atau mengganti API key, hubungi administrator MAESTRO.
